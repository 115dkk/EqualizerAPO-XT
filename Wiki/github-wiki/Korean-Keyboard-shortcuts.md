# 단축키

설정 편집기가 알아듣는 키와 마우스 동작을 한곳에 모았습니다.

자주 쓰는 것부터 적습니다.

* **노브를 끌면서 Shift**를 누르면 평소의 10분의 1 속도로 돌아가 미세하게 조절할 수 있습니다.
* **값 상자를 끌면서 Shift**를 누르면 4배 더 촘촘하게 움직입니다.
* Preamp, Delay, All-pass 카드의 **노브를 두 번 클릭**하면 기본값으로 돌아갑니다.
* **Ctrl+Z / Ctrl+Y**는 필터 목록의 변경을 되돌리고 다시 적용합니다.

## 메뉴

| 키 | 메뉴 항목 | 하는 일 |
|---|---|---|
| Ctrl+N | 파일 > 새로 만들기 | 새 설정을 엽니다 |
| Ctrl+O | 파일 > 열기 | 설정 파일을 엽니다 |
| Ctrl+S | 파일 > 저장 | 지금 탭을 저장합니다 |
| Alt+F4 | 파일 > 종료 | 편집기를 닫습니다 |
| Ctrl+Z | 편집 > 수정 취소 | 필터 목록의 마지막 변경을 되돌립니다 |
| Ctrl+Y | 편집 > 다시 수정 | 되돌린 변경을 다시 적용합니다(Ctrl+Shift+Z는 쓰지 않습니다) |
| Ctrl+X | 편집 > 잘라내기 | 선택한 줄을 잘라냅니다 |
| Ctrl+C | 편집 > 복사 | 선택한 줄을 텍스트로 복사합니다 |
| Ctrl+V | 편집 > 붙여넣기 | 필터 목록에 줄을 붙여 넣습니다 |
| Ctrl+A | 편집 > 모두 선택 | 모든 줄을 선택합니다 |
| Ctrl+Alt+1 ~ Ctrl+Alt+5 | 보기 > 인터페이스 | 스킨을 바꿉니다. 1 Studio Glass, 2 Precision Minimal, 3 Stock Flat, 4 Hardware Rack, 5 Signal Matrix |
| Ctrl+Alt+D | 보기 > 인터페이스 > 어두운 테마 | 밝은 테마와 어두운 테마를 오갑니다 |
| Ctrl+Alt+F | 보기 > 인터페이스 > 그래프 전체화면 | 필터 목록과 도구 모음을 숨기고 분석 그래프를 창 가득 띄웁니다 |

스킨과 테마 단축키는 **Legacy rows**에서는 동작하지 않습니다. 텍스트 입력란에 포커스가 있으면 Ctrl+Z, Ctrl+Y, Ctrl+X, Ctrl+C, Ctrl+V, Ctrl+A는 필터 목록이 아니라 그 입력란의 글자에 작용합니다.

제거 버튼이나 Delete 키로 줄을 지우면 **수정 취소** 버튼이 달린 알림이 8초 동안 떠 있습니다. 저장하지 않은 변경이 있는 탭이나 창을 닫을 때는 Enter가 저장, Esc가 취소입니다.

## 필터 목록

필터 목록에 포커스가 있을 때 카드와 Legacy rows 모두에서 동작합니다.

| 키나 동작 | 하는 일 |
|---|---|
| 위 / 아래 | 이전 줄이나 다음 줄로 옮기고 그 줄만 선택합니다 |
| Shift+위 / Shift+아래 | 선택 범위를 늘립니다 |
| Ctrl+위 / Ctrl+아래 | 선택은 그대로 두고 포커스만 옮깁니다 |
| Space | 포커스가 있는 줄을 선택합니다 |
| Ctrl+Space | 포커스가 있는 줄을 선택에 넣거나 뺍니다 |
| F2 | 포커스가 있는 줄을 원본 텍스트로 편집합니다 |
| Delete | 선택한 줄을 지웁니다 |
| 클릭 | 그 줄을 선택합니다 |
| Ctrl+클릭 | 줄을 선택에 넣거나 뺍니다 |
| Shift+클릭 | 마지막으로 선택한 줄부터 이 줄까지 모두 선택합니다 |
| 줄의 머리 부분을 끌기 | 선택한 줄을 옮깁니다. 놓을 때 **Ctrl**을 누르고 있으면 옮기지 않고 복사합니다 |

이미 선택에 들어 있는 줄을 클릭하면 선택이 유지되므로 여러 줄을 한꺼번에 끌 수 있습니다. 줄을 다른 탭에 놓으면 그 탭으로 옮겨집니다.

줄을 원본 텍스트로 편집할 때는 Enter를 누르거나 다른 곳을 클릭하면 적용됩니다. Legacy rows에서는 Esc가 편집을 취소하고 원래 텍스트로 되돌리지만, 카드에서는 Esc로 취소되지 않습니다.

목록 위에서 마우스 휠을 돌리면 목록이 스크롤됩니다. 카드 안의 노브, 값 상자, 드롭다운 목록은 먼저 클릭해야 휠을 받습니다.

목록 맨 아래의 **필터 추가**와 **맨 위에 필터 삽입**은 클릭뿐 아니라 Enter나 Space로도 필터 선택 창을 엽니다.

## 노브

노브는 Preamp, Delay, All-pass 카드와 Legacy rows의 필터, 지연, 라우드니스 보정 편집기에 있습니다.

| 동작 | 하는 일 |
|---|---|
| 끌기 | 노브를 돌립니다. Studio Glass, Stock Flat, Hardware Rack, Signal Matrix와 Legacy rows에서는 노브가 호를 따라 포인터를 따라오고, Precision Minimal에서는 위아래로 끌며 200픽셀이 전체 범위입니다 |
| 끌면서 **Shift** | 10분의 1 속도로 돌립니다 |
| 두 번 클릭 | 기본값으로 되돌립니다. Preamp는 0 dB, Delay는 0, All-pass는 100 Hz와 기본 Q입니다 |
| 위 / 아래, 왼쪽 / 오른쪽 | 한 단계(Preamp 카드에서는 0.1 dB) |
| Page Up / Page Down | 열 단계 |
| Home / End | 최솟값 / 최댓값 |
| 휠 | 노브를 클릭한 뒤에 돌립니다 |

두 번 클릭으로 되돌리는 기능은 Preamp, Delay, All-pass 카드에만 있습니다. Legacy rows 편집기의 노브는 되돌리지 않습니다.

노브 아래의 숫자를 두 번 클릭하면 직접 입력할 수 있습니다. Enter를 누르거나 다른 곳을 클릭하면 입력한 값이 적용됩니다.

## 값 상자

값 상자는 화살표 없는 숫자 칸입니다. Graphic EQ 카드의 주파수와 게인, IIR과 Velvet 카드, Legacy rows 편집기의 숫자 칸이 여기에 해당합니다.

| 동작 | 하는 일 |
|---|---|
| 숫자 위에서 위아래로 끌기 | 약 4픽셀마다 한 단계씩 바꿉니다. 옆으로 끌면 글자가 선택됩니다 |
| 끌면서 **Shift** | 16픽셀마다 한 단계로, 4배 촘촘하게 움직입니다. 끄는 도중에 Shift를 누르거나 떼도 됩니다 |
| 위 / 아래 | 한 단계 |
| Page Up / Page Down | 열 단계 |
| 휠 | 상자를 클릭한 뒤에 바꿉니다. Ctrl을 누르고 휠을 돌리면 열 단계씩 움직입니다 |

## Graphic EQ

Graphic EQ 카드의 그래프에서는 다음과 같이 동작합니다.

| 키나 동작 | 하는 일 |
|---|---|
| 점 클릭 | 그 점을 선택합니다. Ctrl+클릭은 선택에 넣거나 뺍니다 |
| 점 끌기 | 점을 옮깁니다 |
| 위 / 아래 | 포커스가 있는 점을 1 dB 올리거나 내립니다 |
| 왼쪽 / 오른쪽 | 포커스가 있는 점을 1 Hz 옮깁니다(가변 밴드 배치에서만) |
| Delete / Backspace | 선택한 점을 지웁니다(가변 밴드 배치에서만) |
| 빈 곳을 두 번 클릭 | 점을 추가합니다(가변 밴드 배치에서만) |
| 휠 | 포인터를 중심으로 dB 축을 확대하고 축소합니다 |
| 오른쪽 버튼으로 끌기 | dB 축을 위아래로 옮깁니다 |

화살표 키는 포커스가 있는 점 하나만 옮기고, 이 그래프에는 Shift 미세조정이 없습니다. Legacy rows 편집기에서는 화살표 키가 선택한 점을 모두 옮기고, 휠은 두 축을 함께 확대합니다(포인터가 한쪽 눈금자 위에 있으면 그 축만). Backspace로는 점을 지우지 않습니다.

## 그 밖의 카드

* **여러 선택지가 있는 스위치**(All-pass 차수, Hilbert 방향, Velvet 모드, 분석 지표): 왼쪽 / 위는 이전, 오른쪽 / 아래는 다음, Home과 End는 처음과 끝입니다.
* **Channel과 NewChannel 카드:** 채널 추가 칸에 이름을 입력한 뒤 Enter를 누르십시오.
* **서브우퍼 라우팅 카드:** 두 번 클릭하거나 Enter를 누르면 라우팅 편집기가 열립니다.
* **Include와 VST 카드:** 파일 이름이나 플러그인 이름을 클릭하면 파일이나 플러그인 패널이 열립니다.
* **VST 카드:** 버스 레이아웃 선택기와 슬롯 채널 칸은 Space, Enter, 아래 키로 메뉴를 열고, 채널 채우기 스위치는 Space나 Enter로 켜고 끕니다.

## Copy와 채널 라우팅

Copy 카드의 라우팅 화면은 스킨마다 다르게 동작합니다.

* **Studio Glass:** 선을 클릭하면 선택하고, Ctrl+클릭으로 선택에 넣거나 뺍니다. 한 채널에서 다른 채널로 끌면 둘을 잇습니다. 채널을 클릭하면 그 채널의 선을 모두 선택합니다. 선을 두 번 클릭하면 배율을 바꿀 수 있습니다. Delete나 Backspace는 선택한 선을 지웁니다.
* **Hardware Rack과 Signal Matrix:** 교차점을 클릭하면 배율 1로 잇거나 끊고, 두 번 클릭하면 배율을 입력할 수 있습니다.
* **Precision Minimal과 Stock Flat:** 항을 두 번 클릭하면 편집할 수 있습니다.
* **Legacy rows:** Delete는 선택한 연결을 지웁니다. 연결을 두 번 클릭하면 배율을 편집할 수 있고, Esc는 편집을 취소합니다.

## 필터 선택 창

필터 추가나 카드의 **+** 버튼으로 연 선택 창은 Esc를 누르거나 바깥을 클릭하면 닫힙니다.

* **Studio Glass, Stock Flat, Hardware Rack과 기본 선택 창:** 글자를 입력하면 검색합니다. 위 / 아래와 Page Up / Page Down으로 목록을 옮겨 다니고 Enter로 고릅니다.
* **Precision Minimal:** 위 / 아래는 한 항목, Page Up / Page Down은 열 항목씩 옮기고 Enter로 고릅니다.
* **Signal Matrix:** 글자를 입력하면 검색하고 Backspace로 한 글자씩 지웁니다. 위 / 아래로 옮기고, 왼쪽 / 오른쪽과 Page Up / Page Down으로 묶음을 바꾸고, Home / End로 처음과 끝 항목에 갑니다. Enter로 고릅니다.

## 창

기본 제목 표시줄이 아닌 편집기 자체의 제목 표시줄에서는 제목을 두 번 클릭하면 창을 최대화하거나 원래 크기로 되돌립니다. 대화상자에서는 Enter가 확인, Esc가 취소입니다.

## 장치 선택기

장치 선택기에서는 **문제 해결 옵션** 머리글을 Space나 Enter로 펼치고 접습니다(Tab으로 이동합니다). 장치를 오른쪽 클릭하면 그 장치의 `Device:` 명령을 복사할 수 있습니다. Enter가 확인, Esc가 취소입니다.
