# Hardware Rack (rack)

19인치 랙의 앰프 페이스플레이트. 손에 닿을 듯한 기계. 레거시 alias `industrial`이 이 스킨으로 해석된다.

## 철학

다섯 스킨 중 유일한 정직한 스큐어모피즘이다. 모든 행이 랙 유닛이고 모든 컨트롤이 물리 부품이다(브러시드 메탈 페이스플레이트, 랙 이어, 네 귀퉁이의 일자 나사, 상태 LED, Include 유닛의 패치베이 잭, VST 유닛의 황동 명판). 약속은 "이 장비는 만질 수 있을 것처럼 생겼고 실제 하드웨어처럼 행동한다"이다. 모든 스트로크의 공식 타이브레이커는 한 질문이다. 이것이 하드웨어 페이스플레이트에 있을 물건인가. 나사, 홈, LED, 각인 인쇄는 예다. 글로우, 값 호, 추상 장식은 아니오다. 예외는 얇은 키보드 포커스 링과 호버 하이라이트뿐이고 의도적으로 작게 유지한다.

## 불변 규칙

1. **페인트만, 이미지 금지.** 나사·결·명판·LED 전부 QPainter로 그린다. 비트맵이 들어오면 DPI 독립성과 토큰 일관성(다크 = 베이클라이트/강철, 라이트 = 크림 알루미늄)이 깨진다.
2. **모서리 3px = 기계 가공 코너.** `rack-radius`. 둥글지도 직각도 아닌 모따기된 금속이다.
3. **위계 = 물리 깊이.** 돌출(주요 컨트롤), 평면(라벨), 함몰(입력 우물)로 만든다. 함몰면은 부품으로 설계된 것(LCD·LED 우물, 인서트 유닛의 함몰 베드)만 허용한다.
4. **상태 = 램프, 램프 = paintLed 문법.** 모든 램프는 베젤 링 + 돔 + 스펙큘러를 거치고 후광은 점등 시에만이다. 다크 마감에서 맨 발광 원반은 부품이 아니라 도료로 읽힌다.
5. **전원 내림 = 비활성.** LED를 끄고 어두운 필름을 덮되 나사·결·명판·각인은 남긴다. 장비를 치우는 것이 아니라 끄는 것이다.
6. **색 절제.** 액센트는 앰버 `rack-accent`, accent2는 LED 녹색 `rack-accent2`다. 색은 램프와 각인에만 산다.
7. **표시창 조항.** 디스플레이(LCD, 판독창, 스코프 유리)는 패널 마감을 따르지 않고 두 마감 모두 어두운 우물(`rack-graph`) + 발광 세그먼트로 그린다. 크림색 패널에 박힌 LCD도 여전히 LCD다. 라이트의 스코프 그리드는 `rack-scope-grid`다.
8. **각인 조항.** 라벨은 자간을 띄운 대문자 각인풍 활자(`engraved`)로 쓴다. 각인 문구(`MODULE SELECT`, `NO SIGNAL`, `EAPO-XT SERIES`)는 하드웨어 인쇄물이라 번역하지 않고 진짜 UI 입력 요소만 번역한다.
9. **raw 원문 인쇄 금지.** 패널에 raw 설정 원문을 인쇄하지 않는다. 원본 명령 편집 아이콘은 연필이 아니다(연필은 Include의 파일 내용 편집이 쓴다).
10. **이어 존 불가침.** 페이스플레이트 양끝의 랙 이어 폭은 콘텐츠 금지 구역이다. VST 행은 명판 폭을 추가로 비운다.
11. **chrome은 RackChrome에.** 그리기 코드는 한곳에 모으고 스킨 클래스는 얇은 등록 심으로 유지한다.

## 빛과 상태의 문법

hover는 페이스플레이트 광택이 오르고(`rack-card`에서 `rack-card-hover`) 하드웨어 가장자리를 앰버로 덥힌다. selected는 따뜻한 패널 색(`rack-card-selected`)과 앰버 보더를 입고 픽커 슬롯은 LED가 앰버로 점등된다. focused는 `rack-focus` 보더(기계의 선택 프레임)다. disabled는 전원 내린 유닛이다. 빈 결과는 플레이트에 `NO SIGNAL`을 각인한다.

## 색의 의미론

다크는 `rack-bg` #0b0d0f(랙 내부의 어둠), `rack-card` #1d2328(강철·베이클라이트), `rack-text` #e6e0d4(따뜻한 상아, 차가운 흰색 금지)다. 라이트는 크림 알루미늄 계열이고 보더는 황동기 도는 베이지 `rack-border`다. 평상시 유닛 보더는 토큰 보더가 아니라 랙 개구부의 어두운 솔기 `rack-seam`이고, 안쪽에 한 방향 작업등을 따르는 모따기(상·좌 = 빛, 하·우 = 그림자)를 두른다. 그래프 영역은 깊은 초록빛(`rack-graph`, `rack-grid-minor`)으로 오실로스코프 유리의 기억이다. 표시창과 스코프 유리의 어두운 우물은 코드가 `rack-graph` 토큰이 아니라 `RackPalette`의 리터럴(`LcdWindowGlass`, `GlassTop`/`GlassBottom`)로 칠한다. 라이트의 `rack-graph`는 크림색이라 표시창에 쓰이지 않고, 미리보기도 라이트의 우물 색을 그 리터럴 값으로 적었다. 채널 그룹은 DottedLine, 배지는 채움 없는 와이어(WireframeBorder) 안에 픽토그램을 타입 잉크로 인쇄한다. 헌법 문서가 적은 라이트 배경 #E7E2D8과 카드 #FFFAEF는 코드(`rack-bg` #e2ddd3, `rack-card` #e7e2d7)와 어긋나며 코드가 정본이다.

## 타이포그래피

본문은 `body-rack`(10pt)로 다섯 스킨 중 한 단 작다. 라벨은 `engraved`, 값은 LCD 세그먼트 잉크(`rack-accent2`)의 `readout`이다. 콘덴스드 폰트가 없어 자간 띄운 `EAPO Sans`로 각인을 근사한다. 페인터가 px로 고정한 각인(이어 스텐실, 명판, 노브의 -/+, 판독창, 패치 필드 라벨)은 #300의 활자 한 단계를 뒤늦게 받아 1px씩 컸다.

랙 이어의 유닛 표기(`FILTER`, `PATCH`, `VST`, `ROUTE` 등)는 아래 나사와 SELECT LED 사이를 따라 아래에서 위로 9px 굵은 대문자(자간 1.5px)로 찍는다. 높이 96px 이상인 유닛에서 단어 전체가 그 사이에 들어갈 때만 찍고, 들어가지 않으면 자르지 않고 뺀다. 가장 낮은 채널 카드만 예외로 활자를 줄여(지금은 6px) `CHANNEL` 전체를 찍는다(ADR 0001). 카드 상태 문장(버스 거부 사유, 서비스가 읽을 수 없는 위치, 로더 오류)은 유닛 줄 안에 넣지 않고 그 아래 판 전폭에 한 줄을 따로 써서 길면 줄바꿈한다. 유닛 줄이 판보다 넓어 문장이 먼저 말줄임으로 잘렸기 때문이다.

## 하지 말 것

이미지·비트맵 에셋 도입. 평면 디자인 어휘 혼입(채운 색 배지, 그림자 없는 플랫 카드, 형광 액센트). 디스플레이를 패널 마감에 맞추기. 페이스플레이트에 raw 원문 인쇄. 각인 문구에 tr() 적용. 이어 존에 콘텐츠 배치. 차가운 흰색·회색 텍스트. 램프를 맨 발광 원반으로 그리기.

## 이웃과의 경계

soft도 깊이를 다루지만 soft의 고도는 명도 스텝의 추상이고 rack의 깊이는 부품의 물리다. matrix도 점등 어휘를 쓰지만 matrix의 LED는 보드 위의 추상 신호이고 rack의 LED는 베젤에 박힌 물리 부품이다. rack에서 격자 좌표나 모노 코드 셀이 보이면 matrix를 침범한 것이다.
