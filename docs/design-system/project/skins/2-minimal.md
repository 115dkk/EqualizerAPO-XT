# Precision Minimal (minimal)

은행 창구의 단말기. 활자, 헤어라인, 정렬이 전부다. 시트 파일 이름은 옛 이름 그대로 `precision_*.qss`다.

## 철학

'장식이 없을 때 정보가 가장 정확하다'는 학술적·공학적 절제의 스킨이다. 화면은 문서이고 행은 문장이며 상태는 잉크의 농도다. 약속은 하나다. 화면에 있는 모든 픽셀은 정보다. 글리프는 의미를 운반하고 선은 구획을 나누며 명도 단계는 상태를 표시한다. 다섯 스킨 중 밀도가 가장 높고(`minimal-row-height` 32px), 색이 가장 적으며(무채색 회색 + `minimal-accent` 하나), 키보드 친화도가 가장 높다.

## 불변 규칙

1. **라운드 0.** 포커스 표시조차 정사각 헤어라인 프레임이다.
2. **1px 헤어라인.** 모든 선은 `minimal-border`의 1px다. 두꺼운 보더, 색 레일, 그림자를 금지한다.
3. **상태 = 배경 명도 스텝.** 호버는 `minimal-card`에서 `minimal-card-hover`로 정확히 한 스텝 위, 비활성은 한 스텝 아래(`minimal-surface`)다.
4. **모노스페이스가 UI 서체다.** 본문과 수치 모두 `EAPO Mono`이고 크기는 하나다. 위계는 밝기로 만든다.
5. **정보의 중요도 = 잉크의 밝기.** 수치·명령어·데이터는 `minimal-ink-bright`, 본문은 `minimal-text`, 캡션과 메타데이터는 `minimal-muted`, 죽은 코드와 미측정은 그 아래로 가라앉는다.
6. **글리프는 정보, 색은 태그.** 행머리의 ASCII 글리프(`~` 필터, `>>` Include, `[]` VST, `->` Copy, `#` 주석)는 종류를 말하는 형태 정보다. 미지정 명령은 가운뎃점(`·`)으로 칸만 지킨다. 배지는 외곽선만 남기고 채움을 주지 않는다.
7. **소스는 ASCII.** 코드 안의 글리프는 ASCII이거나 코드포인트로 만든다. DM Mono에 없는 글리프는 두부가 된다. 화살이 필요하면 `>`를 쓴다.
8. **액센트는 활성 중에만.** 평소엔 무채색이고 드래그·입력 중인 컨트롤만 `minimal-accent`를 입는다.
9. **키보드로 완결한다.** 키 문법은 화면 어딘가에 적혀 있어야 한다(정본은 픽커의 man-page 푸터).

## 빛과 상태의 문법

hover는 배경 한 스텝 상승, 그게 전부다. selected는 본문 잉크 헤어라인 프레임이고 픽커에서는 반전 블록이다. 옛 파란 선택 면 `minimal-card-selected`는 2026-08-24 재판정으로 폐기되어 소비처가 없다. focused(리스트 커서)는 본문 잉크 헤어라인 프레임 + 행번호 셀의 반전 블록이다. dragging/armed는 그 컨트롤의 잉크가 액센트로 바뀐다. disabled는 행머리에 `#`을 달고 배경이 한 스텝 가라앉는다. zebraStripe는 켠다.

재사용하는 표기 문법은 셋이다. 반전 블록(reverse video)은 가장 강한 표기이자 선택 커서의 정본으로, `minimal-text`와 `minimal-surface`의 엄격한 맞교환으로만 만든다. 각인 명령 캐논은 액션을 미번역 대문자 모노 각인(`command` 스타일)으로 쓰며 휴지는 보조 잉크, 호버는 그라운드 한 스텝과 본문 밝기, 포커스는 정사각 액센트 헤어라인 프레임, 눌림은 반전 블록이다. 점선 헤어라인은 '검증된 실체 없음'의 표지다.

## 타이포그래피

`EAPO Mono` 단일이고 이탤릭은 없다. 캡션은 대문자와 자간으로 구분한다. 강조는 굵기나 밝기로 만들고 크기를 키우지 않는다. 숫자 칼럼은 0패딩으로 폭을 고정하고, 좁은 폭에서 긴 값을 만나면 잘라내지 않고 폰트를 줄인다.

## 채널 잉크

콘솔 그라운드에서 채워진 칩은 GUI 배지 어휘라서 채널은 맨 잉크로 인쇄한다. `minimal-ch-*` 표는 공유 팔레트의 단순 탈색이 아니라 ANSI/base16 색상 가족에 다시 배치한 설계 표(이웃 간 최소 24도)이고, SBL·SBR은 빈 색상환 구역(violet 300, olive 95)으로 옮겼다. 라이트 값은 모두 그라운드 대비 4.3:1 이상이다. 표 밖의 채널(ALL, 번호 채널)은 `channel-neutral`을 같은 명도로 누른 `minimal-ch-neutral`로 인쇄하고, 장치에 없는 가상 채널은 같은 잉크에 1px 파선 테두리를 두른다.

## 하지 말 것

곡률, 그림자, 글로우, 그라데이션. 상태를 새 색으로 표현하기. 글리프를 장식으로 추가하기. 두 가지 폰트 크기로 위계 만들기. 비-ASCII 글리프를 소스에 직접 넣기. 키보드 동선을 끊는 마우스 전용 UI. If 가족의 분기 행을 멤버 깊이로 밀기. 분기 판정에 상태색 입히기.

## 이웃과의 경계

혼동 위험이 가장 큰 이웃은 matrix다(둘 다 모노, 1px 룰, 라운드 0). minimal은 문서와 터미널(텍스트의 줄, 줄무늬, 무채색, 상태 = 잉크 농도)이고 matrix는 계기판(격자 텍스처, 좌표, 신호등 상태색, LED, 상태 = 점등)이다. minimal에 격자 텍스처나 상태색 램프나 좌표가 들어오면 matrix를 침범한 것이다.
