# Signal Matrix (matrix)

공항 출발 안내판, 방송 라우팅 매트릭스. 좌표를 가진 셀의 보드.

## 철학

'화면은 보드다'라는 단일한 은유로 움직인다. 사용자는 메뉴를 살펴보는 것이 아니라 계기판을 조작한다. 행을 고르는 것은 버스를 선택하는 것이고 항목을 고르는 것은 크로스포인트를 체결하는 것이다. 색은 상태에만 배급되어 카탈로그는 단색이고, 램프 하나가 켜지는 순간이 가장 크게 읽힌다. 치수는 전부 모눈 위에 앉는다. 정렬은 미덕이 아니라 규칙이다.

## 불변 규칙

1. **색 배급제.** 신호등 색은 상태 전용이고 장식에 쓰지 않는다. `matrix-accent` 시안은 체결·선택·호버 예고와 라우팅된 신호 데이터 전용, `matrix-accent2` 녹청은 바이폴라 컷 방향 전용이다. 카탈로그·라벨·배지는 단색이다. 비활성은 색이 아니라 형태(점선 룰, 속 빈 램프, 취소선, 저알파)로 말한다.
2. **라운드 0 + 1px 룰.** 직각 셀과 `matrix-border`의 1px 괘선만 쓴다. 곡률·그림자·글로우를 금지한다.
3. **모든 것은 격자 위에.** `matrix-grid-pitch` 24px가 보드의 모눈이고 행 높이 36과 채널 들여쓰기 24를 비롯한 치수는 이 피치의 배수다. 카드 본문 뒤의 흐린 세로 모눈선은 보드의 정체성이지만 보드 표면(카드 사이·헤더 주변)까지이고, 행 본문은 불투명 에디터 패널이 모눈을 덮는다.
4. **행 = 좌표를 가진 셀.** 행은 왼쪽 `matrix-card-rail` 3px 상태 레일, 거터의 5px 상태 램프(실선 녹 = 가동, 테두리만 앰버 = 바이패스), `matrix-coordinate-band` 120px 좌표 밴드를 가진다. 행 번호 셀은 버스 문자 + 줄 번호(`B3` = 3행의 BiQuad)이고 유일성은 줄 번호가 책임진다. 좌표 잉크는 평시 `matrix-muted`, 체결 시에만 액센트다. 좌표는 재부여하지 않는다.
5. **수치는 모노 + 박스 셀.** 권위 있는 판독값은 언제나 박스 안의 모노 숫자다. 함몰 배경(`matrix-graph`) + 1px 룰 + 굵은 모노 잉크(`readout`)의 라운드 0 셀이 표준형이다.
6. **크로스포인트 호버.** 호버는 행 밴드와 좌표 칼럼 밴드를 동시에 켜고 둘의 교차부가 가장 밝다(α 22/14/26).
7. **크리스프 1px.** 셀·괘선·모눈은 안티에일리어싱을 끈다. 곡선 데이터(트레이스)에만 AA를 허용한다.
8. **텍스트 화살은 ASCII만.** 방향·캐럿 글리프는 페인트로 그리고 텍스트 화살은 `>`만 허용한다.

## 색 의미론

| 색 | 의미 | 구현 위치 |
|---|---|---|
| `matrix-success` 녹 | 가동/저장됨 | 행 레일·상태 램프, 툴바 램프(저장됨), Copy 유니티 셀(`1`) |
| `matrix-warning` 앰버 | 바이패스/수정됨/주의 | 행 레일·속 빈 램프, 툴바 램프(수정됨), 포맷 배지, 클립 해저드 존 |
| `matrix-danger` 적 | 음수/위험/파괴적 동작 | Copy 음수 계수(`INV`), Include 오류 판독, 닫기 셀 프리라이트 |
| `matrix-accent` 시안 | 체결·선택·호버 예고, 라우팅된 신호 데이터 | 체결 셀 LED, 선택 룰, 크로스포인트 밴드, 패치 트레이스, 스캔 캐럿, 응답 트레이스 |
| `matrix-accent2` 녹청 | 바이폴라 컷 방향 | gain 노브의 좌측 세그먼트, GraphicEQ 스템의 0 dB 아래 구간 |

이 다섯 줄 밖의 색 사용은 전부 장식이며 금지다.

## 빛과 상태의 문법

hover는 크로스포인트 예고다. selected/engaged는 셀 체결(액센트 LED 채움 + 1px 액센트 룰)이고 픽커의 활성 버스는 3px 체결 밴드를 받는다. focused는 정사각 셀 브래킷이다. disabled는 결항 처리된 출발편(점선 외곽 룰 + 속이 빈 앰버 램프 + 제목 취소선)이고 행은 보드에 남는다. dragging은 점등 색이 lighter(130), 호버는 lighter(115)다.

## 타이포그래피

라벨은 `EAPO Sans`, 수치·코드·좌표는 `EAPO Mono`다. 위계는 격자 위치와 균일한 활자가 만들고 크기 변화로 위계를 만들지 않는다. 타입 코드는 `BQUAD`, `INC`, `VST` 같은 모노 약호이되 배지의 내용물은 픽토그램이고 잉크는 보드 잉크 단색이다.

## 하지 말 것

신호등 색·액센트를 장식이나 타입 식별에 쓰기. 곡률, 그림자, 글로우, 그라데이션 장식. 모눈 텍스처 지우기, 비-배수 치수 들이기. 타입 배지에 색 입히기. AA를 켠 채 1px 괘선 그리기. 좌표·번호 재부여. 비활성 행을 숨기거나 흐리게 뭉개기. 스킵 행에 취소선 걸기(취소선은 바이패스의 문법). 분기 거짓·스킵에 danger 쓰기.

## 이웃과의 경계

가장 가까운 이웃은 minimal이다. matrix가 좌표와 램프를 잃으면 minimal로 퇴화하고 minimal이 상태색과 격자를 얻으면 matrix를 침범한다. 점등 어휘는 rack과도 닿지만 rack의 LED는 베젤에 박힌 물리 부품이고 matrix의 LED는 보드 셀의 추상 점등이다(스큐어모피즘 금지).
