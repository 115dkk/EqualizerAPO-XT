# DeviceSelector

Equalizer APO를 설치할 장치를 고르는 별도 실행 파일의 대화상자다. `SkinThemeData` 한 단위와 QSS 자원만으로 Editor와 같은 스킨을 입고, 폼 계약은 `DeviceSkinPainter`가, 스킨별 계기는 `DeviceSelector/skins/<Skin>DeviceSkin.cpp`가 그린다. 미리보기는 `DeviceSelector --skin-shots`의 `normal` 장면(760x700)을 옮겼다.

## 공유 계약

제목 문장, 재생 장치와 녹음 장치 두 섹션(접을 수 있다), 장치마다 설치 토글·연결 이름·상태 문장·태그(`DEFAULT`, `EXP`)·엔드포인트 번호(`OUT #n`/`IN #n`), 문제 해결 옵션 디스클로저, OK·Cancel 버튼으로 이루어진다. 설치·제거가 대기 중인 행은 그 사실을 상태 문장과 토글이 함께 말하고, 사용 불가 엔드포인트는 경고가 아니라 물러난 형태다.

## 스킨별 재질

- **studio:** 빛나는 유리 모니터링 콘솔이다. 엔드포인트는 리스트 스케일의 유리 채널 스트립이고 설치 토글은 점등 콘솔 푸시버튼(LED 위의 유리 캡이 체결 전에는 소켓 속에 어둡게 앉아 있다가 체결되면 안에서부터 액센트로 빛난다). 섹션은 발광 헤어라인 아래의 각인 캡션, 선택된 스트립은 액센트 보더 글로우, 사용 불가 스트립은 스모크 글라스다.
- **minimal:** 터미널 메뉴다. 장치는 그려 넣은 `[x]`/`[ ]` 토글 박스 + 0패딩 유닛 번호 + 명령어 자리의 연결 이름 + 흐린 `:: 상태` 둘째 줄의 두 줄 엔트리다. 섹션은 `== 캡션 ==` 구분 룰, 선택은 정사각 액센트 헤어라인, 사용 불가는 주석 처리된 줄, 버튼은 대괄호 명령.
- **soft:** 큰 둥근 장치 카드와 결과를 미리 보여 주는 큰 둥근 체크 웰이다. 상태 문장 앞의 파스텔 상태 점(녹색 이미 괜찮음, 파랑 설치 예정, 앰버 한 번 더 볼 것, 뮤트 휴지)은 전부 파스텔 선반을 거쳐 어떤 점도 경보가 아니다. 섹션은 파스텔 알약, 버튼은 도톰한 스타디움.
- **rack:** 패치 베이다. 토글은 1/4인치 패치 잭이라 체결하면 플러그가 잭에 앉고, 패널 램프가 설치 상태를 말한다(녹색 유지, 앰버 변경 대기, 소등 손대지 않음). 섹션은 DZUS 쿼터턴 파스너를 단 마운팅 레일이고 `BAY NN`과 PLAY/REC 스탬프는 하드웨어 인쇄, 사용 불가 베이는 전원 내린 유닛, 버튼은 기계 가공 캡이다.
- **matrix:** 타깃 획득 보드다. 섹션 왼쪽 레인을 세로 버스 트레이스가 내려가고 장치 행의 토글은 그 위의 정사각 포트 노드(빈 셀 대기, LED 채움 + 통전 트레이스 패치됨)다. 포트는 `P0..`/`C0..` 좌표를 받고 호버는 코너 브래킷의 타깃 획득, 선택은 `LOCK` 셀, 사용 불가 행은 점선 스텁 + `OFFLINE` 태그다.

## 상태

hover는 studio 예열, minimal 반전 블록 스윕 + `>` 캐럿, soft 결과 프리뷰, rack 앰버 예열 링 + 플러그 고스트, matrix 타깃 획득 브래킷이다. 선택(트러블슈팅 대상)은 각 스킨의 선택 문법을 따른다.

## 소비자가 주는 것

엔드포인트 목록(이름, 연결, 방향, 기본 장치 여부, 설치 상태, 사용 가능 여부, 실험적 여부)과 대기 중인 변경, 디스클로저 열림 여부. hand-written from `DeviceSelector/skins/<Skin>DeviceSkin.cpp` and `DeviceSelector/skins/DeviceSkinPainter.cpp` against the `--skin-shots` normal scene.
