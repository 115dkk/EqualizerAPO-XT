# FilterPicker

명령 템플릿을 고르는 팝업이다. 픽커 호스트의 팝업과 이벤트 루프, 검색과 키보드 문법은 공용이고 각 스킨은 `picker/<Skin>FilterPicker.cpp`에서 무대와 항목의 표현만 답한다. 심사 기준은 "메뉴를 둘러보는 게 아니라 크로스포인트를 거는 것처럼 보여야 한다"였다.

## 공유 계약

검색은 전체 문자열에 걸리고 문자는 필터, 순수 숫자는 번호 점프, 위아래는 이동, Return은 삽입이다. 항목의 픽토그램은 `Icons` 묶음의 카탈로그 픽토그램이고 미지 템플릿은 모노그램으로 물러난다. 빈 결과는 연출하지 않고 보고한다.

## 스킨별 재질

- **studio:** 떠 있는 프로스트 글래스 패널이다. 깊은 배경의 불투명 무대 스트립(13px), 겹친 스트로크 그림자, 보더를 감싸는 4겹 `studio-accent` 글로우, 윗변의 액센트에서 `studio-accent2`로 가는 발광 호, 유리 뒤의 방사형 광원 둘(검색창 뒤 파란 키 라이트, 아래 모서리 보라 림 라이트). 검색창은 가라앉은 유리의 돋보기 글리프, 섹션 캡션은 은은히 빛나는 구분선. `이름 (설명)` 꼴은 이름과 우측 흐린 캡션(`picker-caption` 9.1pt, α 170, 점등 시 220)으로 갈라 그리고 캡션이 먼저 물러난다. 선택 항목은 안에서부터 빛나고 호버는 커서 아래에 빛이 고인다. 스크롤바 핸들은 채널 위의 유리 조각.
- **minimal:** 번호식 터미널 인덱스다. 맨 위에 `minimal-accent`의 `>` 프롬프트 한 줄과 우측 실시간 매치 카운터(`6/22`), 섹션은 대문자 자간 캡션이 전폭 1px 룰 위에 앉고, 항목은 0패딩 번호 칼럼 + 한 줄 모노 텍스트다. 번호는 페이지 좌표라 필터링해도 바뀌지 않는다. 선택은 반전 블록, 호버는 한 스텝. 맨 아래 man-page 키 범례(`A-Z FILTER · NN JUMP · ↑↓ MOVE · RET INSERT`)가 문법 전체를 명시하고 빈 질의는 `NO MATCH` 한 줄과 `0/NN`이다.
- **soft:** 소비자 설정 앱의 메뉴 카드다. `soft-radius-card` 14px, 스타디움 검색창, 48px 두 줄 행(굵은 이름 + 흐린 비모노 캡션), iOS 설정풍 둥근 사각 색 타일(타입 색을 파스텔 선반에 올린 채움 + `soft-on-ink` 픽토그램), 파스텔 틴트 알약의 카테고리 헤더, 여백뿐인 섹션 구분, 스타디움 하이라이트의 현재 행. 콜론으로 끝나는 템플릿 줄은 "Choose the details after adding"으로, 블록 클로저는 "Complete as it is"로 바꿔 보인다.
- **rack:** 1U 모듈 프리셋 브라우저다. 브러시드 페이스플레이트(기계 가공 1px 엣지, 점등된 상단 베젤, 네 나사), `MODULE SELECT` 각인 헤더 + 녹색 전원 LED(`rack-accent2`), 함몰 LCD 검색창(녹색 세그먼트), 리벳 박힌 각인 섹션 플레이트, 베젤 달린 패널 LED가 붙은 라벨 슬롯. LED는 카드 chrome과 같은 `paintLed` 문법(베젤 링, 돔, 스펙큘러, 점등 시에만 후광)이라 꺼진 LED는 앰버를 어둡게 누른 돔이다. 선택 슬롯은 앰버 점등 + LED 쪽에서 흘러나오는 역광이고, 호버는 LED를 켜지 않고 슬롯에 옅은 램프 빛만 올린다. 켜진 LED는 언제나 선택을 뜻한다. 하단 레일에 `EAPO-XT SERIES`, 빈 검색은 `NO SIGNAL` 각인.
- **matrix:** 버스 레일 × 좌표 칼럼의 2축 계기다. 왼쪽 버스 레일은 카테고리마다 박스 문자(A..G)와 항목 수 판독, 오른쪽 좌표 셀 칼럼은 항목마다 불변 좌표(C1..C8, `coordinate` 스타일). 체결 셀은 `matrix-accent` LED 채움 + 1px 룰, 활성 버스는 3px 체결 밴드, 2px 패치 트레이스가 버스 셀과 커서 셀을 잇는다. 검색은 헤더의 함몰 스캔 판독 스트립(`> _` 캐럿)이고 둥근 검색창은 없다. 푸터는 출발 안내판 한 줄로 체결된 좌표가 삽입할 원문과 좌표를 판독한다. 호버 프리라이트는 α 40, 체결은 48~56. 빈 스캔은 `-- NO SIGNAL --`과 `> NO MATCH`.

## 상태

selected는 studio 내부 발광, minimal 반전 블록, soft 스타디움 하이라이트 + 액센트 외곽선, rack 앰버 점등 슬롯, matrix 체결 셀이다. hover는 studio 빛 고임, minimal·soft 한 스텝, rack 슬롯의 옅은 램프 빛(LED는 꺼진 채), matrix 프리라이트다.

## 소비자가 주는 것

카테고리별 템플릿 목록(이름, 설명, 명령어 id, 픽토그램), 검색어, 선택·호버 인덱스, 매치 카운트. hand-written from `Editor/skins/<id>/picker/<Skin>FilterPicker.cpp`.
