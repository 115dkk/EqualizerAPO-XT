# CopyRouting

Copy 명령의 채널 매핑 뷰다. 파싱과 직렬화(`RoutingFold`, `RoutingPortModel`)는 공용이고 다섯 스킨이 각자의 렌더러(`routing/*RoutingRenderer.cpp`)로 같은 라우팅을 다르게 그린다. 미리보기는 갤러리 `copy_normal`의 라우팅 `VC = 0.5*L + 0.5*R`, `R = L`을 옮겼다.

## 공유 계약

장치 채널은 전부 시딩되어 편집 표면을 유지하되 목록은 접는다. 기본은 명령이 관여하는 채널만 보이고(빈 명령이면 앞 두 장치 채널이 대표) 나머지는 접힘 컨트롤 뒤에 둔다. 가상 채널은 추가하고 지울 수 있지만 장치 채널은 접힐 뿐 지워지지 않는다. 채널 식별 잉크는 `channel-*`(minimal은 `minimal-ch-*`)이고, 유니티 계수는 값을 인쇄하지 않는다. MultiConvolution 카드가 같은 뷰를 고정 소스 모드로 재사용한다.

## 스킨별 재질

- **studio (LightTrace):** 유리 위에 식각된 빛의 회로다. 위 열의 입력 칩과 아래 열의 출력 칩(점등 유리 칩)을 수직 접선의 cubic 곡선 트레이스가 잇고 다섯 렌더러 중 유일하게 곡선을 쓴다. 트레이스 색은 `studio-accent` 하나이고 글로우는 3~4겹 스트로크다. 화살촉은 없고 도착 포트 점이 더 밝다. 계수는 트레이스 위의 가라앉은 유리 판독창이다. 가상 채널 칩은 점선, 가상 출력 추가는 점선 고스트 `+` 칩.
- **minimal (StepList):** `# │ DEST <- SOURCES` 형식의 모노 스텝 리스트다. 0패딩 번호가 페이지 좌표이고 번호 칼럼은 거터 헤어라인으로 분리한다. 채널 토큰은 `minimal-ch-*` 맨몸 잉크, 계수는 `×0.5` 칩, 소스 추가는 대괄호풍 `[+]`, 가상 채널만 점선 프레임이다. 마지막 스텝 아래의 프롬프트 `>`와 정지 블록 커서가 리스트를 닫고 새 가상 채널은 그 프롬프트에 친다.
- **soft (BlockChip):** 각 출력이 하나의 둥근 수식 블록이다. 액센트 가장자리의 둥근 카드 왼쪽에 대상 채널 색의 둥근 막대가 붙고 `VC = 0.5·L + 0.5·R`을 채널 칩과 계수 칩으로 조립한다. 행 끝의 점선 둥근 `[+]`가 소스를 더하고 아래의 점선 `+ Add channel` 칩이 가상 채널 블록을 만든다.
- **rack (HardwarePatchbay):** 브러시드 패널 위 함몰 서브패널의 라우팅 매트릭스 버튼 필드다. 행 = 출력, 열 = 입력의 각인 라벨이 붙고 각 교차점이 정사각 조명 래칭 버튼이다. 휴지 교차점은 민짜 돌출 캡(각인 딤플 하나), 라우팅된 교차점은 latch-down 캡 아래 램프가 켜진다. 유니티는 legend 없이 원형 램프 창만 켜고 계수가 유니티를 벗어날 때만 legend를 인쇄한다(음수 게인은 danger 램프). `ADD` 캡이 새 가상 채널을 패치한다.
- **matrix (Crosspoint):** 입력 채널 = 열, 출력 채널 = 행의 평면 격자다. 셀 부호는 유니티 = `matrix-success`의 `1`, 음수 = `matrix-danger`의 `INV`, 그 외 = `matrix-accent` + 값이다. 가상 채널은 점선 알약 헤더, 접힌 채널은 푸터의 `+N CH` 캡션 키, `+BUS` 캡션 키가 새 가상 버스를 패치한다. 캡션 키의 휴지는 빈 크로스포인트 셀의 문법(1px 룰 + 옅은 채움)이다.

## 상태

클릭은 유니티 토글, 더블클릭은 값 편집, 빈 값은 제거다. 호버는 studio 빛 고임, minimal 한 스텝, soft 한 스텝, rack 앰버 예열, matrix 크로스포인트 프리라이트다.
