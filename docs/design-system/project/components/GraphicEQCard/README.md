# GraphicEQCard

GraphicEQ 행이다. 클린 설치의 첫 카드라 각 스킨의 얼굴이고, 응답 플롯의 모든 픽셀은 `paintGraphicEqPlot`이 그리며 위젯(`GraphicEQPlotWidget`)은 모델과 입력만 갖는다. 툴바 줄(밴드 레이아웃 콤보 + 가져오기·내보내기·반전·정규화·리셋), 플롯, 정밀 입력의 판독 스트립(밴드 캡션, Freq/Gain 값 스크럽) 순서다. 미리보기는 갤러리 `graphiceq_normal`(가변 밴드 5개)을 옮겼다.

## 공유 계약

밴드 테이블은 두지 않는다. 정밀 입력은 플롯 아래 판독 스트립이 맡고 값은 `valueScrub`, 모드는 `paramSelector` 문법을 그대로 탄다. 노드는 휴지<호버<선택의 사다리를 타고 키보드 포커스는 별도 표기를 가진다. 15/31 밴드 잠금 모드에서는 0 dB선에서 노드로 스템이 서서 고전 그래픽 EQ 실루엣이 된다. 직선 그리드는 AA를 끄고 곡선은 데이터라 AA를 허용한다.

## 스킨별 재질

- **studio:** 가라앉은 유리 창(`studio-graph`, 8px 라운드, 윗변 안쪽 1px 어두운 선). 그리드는 물러난 옅은 1px, 라벨은 `EAPO Mono` muted 각인, 0 dB선은 노브의 발광 앵커를 눕힌 것(액센트 블룸 3px + 텍스트 잉크 코어 1px). 곡선은 4겹 스트로크 글로우(9/5.5/3/1.6px)로 발광하고 아래로 액센트 채움이 0 dB선을 향해 소멸한다. 노드는 인디케이터 점 문법(할로 6px + 코어 3px). 액션 버튼은 불 꺼진 유리 칩이 호버에 점등한다.
- **minimal:** 종이 위의 계측 기록이다. 극도로 옅은 1px 헤어라인 격자, 본문 잉크 1px 곡선에 채움 없음, 0 dB는 유일한 본문 잉크 직선, 노드는 그라운드로 뚫린 정사각 헤어라인 틱(호버 한 스텝 채움, 선택 반전 블록, 드래그만 액센트). 밴드 캡션은 대문자 자간의 보조 잉크, 액션 버튼은 스트로크 글리프의 캡션 버튼 캐논이다.
- **soft:** 확립된 둥근 우물(14px, `soft-graph` + 옅은 보더). 그리드는 주요선만 아주 옅게, 0 dB선은 우물 벽에 닿지 않는 부드러운 노치, 곡선은 3px 라운드 캡으로 부스트는 `soft-accent`, 컷은 `soft-accent2` 파스텔이고 아래에 같은 쪽 파스텔의 옅은 워시. 노드는 큰 둥근 점(휴지 5px, 카드 면 + 파스텔 2px 가장자리, 선택은 ON 문법). 액션 버튼은 스타디움 아이콘 필.
- **rack:** 오실로스코프 표시창이다. 인광 유리 우물에 함몰 베젤(처마 그림자 + 점등된 아랫입술), `rack-scope-grid` 그래티큘(크리스프 1px, 메이저 한 단 밝게), 0 dB 축은 인광 틴트 중심선 + 해시 틱, 라벨은 세그먼트 잉크 각인, 곡선은 녹색 인광(`rack-accent2`, 겹친 스트로크 글로우, 축까지 잔광 채움). 노드는 발광 조정 도트(휴지 옅은 돔, 호버 예열, 선택 점등 코어 + 조정 칼라 링). 액션 버튼은 표준 기계 버튼.
- **matrix:** `matrix-graph` 함몰 데이터 셀에 크리스프 1px 모눈(마이너 `matrix-grid-minor`, 메이저 muted 저알파). 0 dB 버스는 본문 잉크 1px 룰, 응답 트레이스는 `matrix-accent` 2px(AA 허용, 채움은 금욕적). 노드는 정사각 크로스포인트 셀(휴지 빈 셀 + muted 룰, 호버 프리라이트 + 행·열 헤어라인, 선택 체결)이고 판독 스트립이 가리키는 밴드는 모노 좌표 태그를 단다. 액션 버튼은 툴바 열차의 투명 기능 셀.

## 상태

비활성은 studio 소등(불투명도 0.45, 경고색 금지), minimal 데이터 잉크 한 스텝 침강, soft 잠듦(고스트 곡선, 격자 제거), rack 전원 내린 표시창(서비스 농도 감광), matrix 결항(저알파 + 점선 외곽 룰)이다. 표면 포커스는 각 스킨의 `*-focus`가 프레임을 두른다.
