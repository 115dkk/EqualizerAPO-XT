# AnalysisGraph

분석 독의 응답 그래프다. GraphicEQ 카드의 응답 계기를 상시 모니터로 넓힌 것으로, 각 스킨의 `*Skin.Analysis.cpp`가 상태 없는 페인터로 전 픽셀을 그린다. 축은 20 Hz부터 20 kHz의 로그 축과 dB 축이고, 그리드는 주·보조 두 계급이며, 0 dB 기준선과 응답 트레이스, 클리핑 고지, 측정 커서, 채널·샘플레이트 캡션을 가진다.

## 공유 계약

축 눈금 라벨 박스는 공유 헬퍼(`skinXTickLabelRect`, `skinYTickLabelRect`)가 그리드 위치를 정하고 스킨은 모양만 답한다. 클리핑(0 dB 초과 가능)은 데이터로서의 위험이라 어느 스킨도 조용히 넘기지 않되 경보의 형태는 스킨의 상태 문법을 따른다. 커서는 호버 진행도로 페이드 인한다. 프레임 라운드는 `graph-radius` 10px가 기본이다.

## 스킨별 재질

- **studio:** 가라앉은 유리 창(`studio-graph`)이다. 그리드는 데이터 뒤로 물러난 크리스프 1px(`studio-grid-minor` α 84/150), 축 숫자는 모노 `studio-muted` 각인이다. 0 dB선은 발광 앵커선이고 응답 트레이스가 창의 유일한 빛으로 4겹 스트로크 글로우를 입으며, 곡선 아래 채움은 0 dB에서 갈라져 부스트 쪽이 한 단 따뜻하다. 클리핑은 0 dB 위의 유리가 `studio-danger` 워시로 데워지고 우상단에 점등 `CLIP` 칩이 선다.
- **minimal:** 넓은 시트에 남은 플로터 기록이다. dB 숫자는 시트 양쪽 여백에 인쇄하고 0 dB 숫자만 `minimal-text`로 찍는다. 0 dB 룰은 유일한 풀 잉크 직선, 응답은 채움도 에코도 없는 본문 잉크 1px 트레이스, 전체를 두르는 정사각 1px 헤어라인 프레임. 클리핑은 reverse video 오류 블록(초과 영역을 시트 레지스터로 가라앉힌 danger로 채우고 트레이스는 그 안에서 반전)과 `!! OVER 0 DB` 태그다. 상단 밴드에 `RESPONSE` 헤더와 커서 판독.
- **soft:** 14px 둥근 우물(`soft-graph` + 옅은 보더)에 응답을 선이 아니라 지형으로 그린다. 컷 골짜기는 `soft-accent` 파스텔, 부스트 언덕은 `soft-success` 파스텔의 불투명 덩어리이고 클립 가능 구간은 `soft-warning`으로 데워진다. 곡선은 각 쪽 파스텔에 웜 잉크를 섞은 3px 라운드 캡 스트로크, 그리드는 주파수 십진 메이저만, 축 캡션은 본문 서체의 흐린 잉크. 클립 고지는 경보가 아니라 이름표와 조언 문장이다.
- **rack:** SPECTRUM MONITOR 유닛이다. 인광 유리 창(`rack-graph`, 표시창 조항)이 기계 가공 베젤에 안착하고 그래티큘은 `rack-scope-grid`의 크리스프 1px, 0 dB 축은 인광 틴트 중심선 + 해시 틱, 축 숫자는 세그먼트 잉크. 빔은 녹색 인광 트레이스(`rack-accent2`)로 겹친 스트로크 글로우와 축까지의 잔광 채움을 가진다. 아래 플레이트 스트립에 `SPECTRUM MONITOR` 각인, 채널 캡션, `OVER` legend와 PEAK 램프(클리핑 중 위험 적색 점등, 앰버 아님).
- **matrix:** 보드의 텔레메트리 모니터다. 함몰 데이터 셀(`matrix-graph` + 1px 룰), 크리스프 정수 1px 모눈(메이저 `matrix-muted` 저알파, 마이너 `matrix-grid-minor`), 모눈에서 펀치해 낸 태그 셀의 축 판독, 0 dB 버스는 본문 잉크 1px 룰, 트레이스는 `matrix-accent` 1px 코어 + 저알파 에코 하나(글로우도 채움도 없음). 클립은 앰버 대각선 해저드 존과 `OVER` 태그 셀. 마스트헤드 `RESPONSE`, 푸터는 `> ` 마커와 채널 캡션과 스팬 판독의 보드 라인.

## 상태

hover는 studio 창 안의 빛이 답하고(트레이스 글로우 한 숨), minimal 커서가 보조 잉크에서 본문 잉크로, soft 렌즈 커서와 알약 판독이 떠오르고, rack 인광이 예열되며, matrix 스캔 룰이 통전된다. 비활성 그래프는 각 스킨의 데이터 잉크가 한 단 가라앉는다.

## 소비자가 주는 것

응답 곡선 샘플, 축 범위, 채널·샘플레이트 캡션, 클리핑 여부, 커서 위치와 호버 진행도. 이 미리보기는 1 kHz +6 dB 피크와 -4 dB 로우 셸프의 합성 응답을 그린 정적 재현이다(hand-written from `Editor/skins/<id>/<Skin>.Analysis.cpp`).
