# ListChrome

카드 목록의 두 가장자리, 첫 카드 위 경계의 호버 삽입선(seam)과 목록 끝의 상시 노출 추가 행(add row)이다. 의미론은 다섯 스킨이 공유하고(카드 추가·삽입의 공유 계약) 스킨은 표현만 답한다.

## 공유 계약

헤더 `+`는 그 카드 바로 앞에 삽입한다. 첫 경계의 삽입선은 호버 시에만 나타나고 휴지에는 아무것도 그리지 않는다. 카드 사이마다 상시 `+`를 늘어놓지 않는다. 맨 끝 add row는 항상 보이며 레거시 툴바가 아니라 스킨별 프레젠테이션을 입는다. 컨트롤은 그 스킨이 이미 가르친 '누를 수 있는 형태'를 입는다(총강 조문 6).

## 스킨별 재질

- **studio:** add row는 아직 판이 끼워지지 않은 유리 슬롯이다. 휴지는 소등 유리(낮은 알파 채움에 희미한 실선 헤어라인, 반사광 없음)이고 점선은 쓰지 않는다(점선은 Include의 재질). 호버는 판이 끼워지는 순간이라 채움이 살아나되 살아 있는 카드의 0.88에는 닿지 않고, 중앙이 밝은 반사선이 점등하며 2겹 `studio-accent` 스트로크가 글로우를 위조한다. 삽입선은 유리 사이로 새어드는 빛으로, 넓고 투명한 스트로크에서 좁은 코어로 가는 3겹 수평 광선이 양끝에서 소멸하고 보라 끝(`studio-accent2`)은 먼 쪽에만 산다. 중앙의 삽입점은 인디케이터 점 문법이다.
- **minimal:** add row는 터미널의 입력 프롬프트 한 줄이다. 카드 컬럼과 같은 인셋의 1px 헤어라인 슬롯에 `+ ADD FILTER`를 좌측 정렬 각인하고, 호버 그라운드 스텝은 `minimal-surface`다. 대시는 금지다(점선은 검증된 실체 없음의 뜻). 삽입선은 텍스트 편집기의 삽입 줄로 1px `minimal-accent` 헤어라인과 줄머리의 정사각 헤어라인 `+` 칸이며 눌림은 칸을 액센트 블록으로 채운다.
- **soft:** add row는 점선 스타디움 슬롯이다. 창 고도를 유지한 점선(불변 규칙 8의 실체 문법)에 가라앉은 조용한 `+` 디스크와 흐린 캡션을 두고 여백을 아끼지 않는다. 호버는 슬롯이 한 스텝 떠오르고 디스크가 ON 문법(`soft-accent` + `soft-on-ink`)으로 켜진다. 삽입선은 파스텔 알약 라인(액센트를 카드 쪽으로 25% 섞은 스타디움 바) + 둥근 `+` 디스크다.
- **rack:** add row는 빈 랙 베이다. 블랭크 패널이 빠진 개구부로 랙 내부가 들여다보이고 내부는 두 마감 모두 어둡다. 개구부의 챔퍼는 페이스플레이트의 역상(윗변 그림자, 아랫입술 작업등)이고 이어 존에는 마운팅 레일과 빈 볼트 구멍이 유닛을 기다린다. 스텐실은 휴지 `EMPTY BAY`, 호버 `INSTALL MODULE`이며 앰버(`rack-accent`)로 예열된다. 삽입선은 서비스 슬롯의 앰버 예열 라인(홈의 그림자 선 + 앰버 열선 + 이어 그루브 위치의 짧은 틱 두 개)이고 원판이나 채움은 없다.
- **matrix:** add row는 아직 게시되지 않은 보드 슬롯이다. 점선 1px 룰이 24px 모눈을 두르고 왼쪽 지정 셀은 버스 문자 대신 `+`를 담는다(문자는 픽커가 게시할 때 배정). 호버는 크로스포인트 프리라이트에 지정 셀 잉크가 `matrix-accent`로 켜지고 누름은 체결이다. 삽입선은 1px 액센트 룰 + 함몰 정사각 삽입 셀(모노 `+`)이며 원판은 이 스킨의 모서리 언어가 아니다.

## 상태

삽입선은 hover에서만 존재하고 pressed는 studio 광선 한 단 밝게, minimal·matrix 액센트 블록/LED 채움, soft 파스텔 한 스텝 깊게, rack 베젤 라인이다. add row의 focus는 각 스킨의 `*-focus` 문법이다.
