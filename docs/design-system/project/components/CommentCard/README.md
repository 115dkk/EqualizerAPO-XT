# CommentCard

주석 행과 맨텍스트(raw) 행이다. 주석은 엔진에게 `#` 뒤가 죽은 코드인 줄이고, 맨텍스트는 모델링되지 않는 원문 줄(맨 노트, If/EndIf 같은 미모델 명령)이다. 미리보기는 갤러리 `comment_normal`과 접힌 `text_normal`을 옮겼다.

## 공유 계약

주석 헤더에는 전원 버튼이 없다(켜고 끌 신호가 없다). 헤더 요약이 노트 원문을 흘리고 본문은 `#` 마커와 편집 가능한 노트로 이루어진다. 맨텍스트 행은 `TXT` 배지와 `Text` 제목, 원문 요약을 가지며 원문은 데이터이지 알람이 아니다. 네 에디터 컨테이너는 투명이라 카드 면 위에 창 배경 패치를 얹지 않는다.

## 스킨별 재질

- **studio:** 불 꺼진 유리, 장식 없음. 휴지의 노트는 잉크만(투명 QLineEdit)이고 호버에 유리가 침강하며 편집에서 가라앉은 유리에 액센트 보더로 점등한다. 맨텍스트는 침강 알파 채움과 어두운 윗변의 8px 데이터 창 하나에 `EAPO Mono` 텍스트 잉크다.
- **minimal:** 소스 주석 레지스터다. 행 전체(마커 + 본문)가 휴지에서 `minimal-muted`로 가라앉고 박스도 입력 크롬도 없다. 호버가 잉크를 본문 밝기로 되올리고 포커스는 1px 액센트 베이스라인의 삽입 모드다. 맨텍스트는 침몰 입력 박스를 벗기고 본문 잉크로 맨몸 인쇄하며 `>_` 마커는 보조 잉크의 raw 태그로 남는다.
- **soft:** 알약이 없는 유일한 카드다. 웜 앰버 파스텔(`soft-warning`, warmer-never-an-alarm)을 메모지 종이색으로 재사용하고 `#`는 메모의 작은 스티커(같은 파스텔의 34px 타일)다. 맨텍스트 원문은 점선 가장자리의 가라앉은 스타디움 우물에 풀 잉크로 앉고 `>_` 글리프는 뺀다.
- **rack:** 다이모 엠보싱 라벨 테이프다. 각인은 공장 인쇄물이고 주석은 현장에서 붙인 것이므로 광택 검정 스트립 + 양각 상아색(#F1E9D8) 활자로 두 마감 모두에서 검정을 유지한다(LCD와는 활자로 구분). 맨텍스트는 AUX 유닛의 프로그래밍 LCD(녹색 모노 세그먼트)다.
- **matrix:** 보드의 리마크 라인이다. 결항 편이 아니므로 취소선을 걸지 않고 레일은 무신호의 `matrix-border` 3px 실선이며 상태 램프는 생략한다. `#` 마커는 침강 지정 셀, 본문은 침강 라인 셀(`matrix-graph` + 1px 룰)에 산다. 행 번호는 `#13`(리마크는 `R`) 버스 문자를 받는다.

## 상태

hover는 studio 유리 침강, minimal 잉크 상승, soft·rack·matrix 한 스텝, focus는 편집 모드(studio 액센트 보더, minimal 밑줄, soft 할로, rack 앰버 엣지, matrix 액센트 룰)다. 주석 처리된 맨텍스트 줄은 잉크가 보조로 가라앉는다.

## 소비자가 주는 것

노트 문자열, 편집 가능 여부, 맨텍스트의 원문 줄. hand-written from `Editor/skins/<id>/<Skin>.CommandRows.cpp` (prepareCommandRow, the comment and text branches) against the gallery shots `comment_normal` and `text_normal`.
