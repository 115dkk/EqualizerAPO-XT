# Knob

회전 파라미터 컨트롤(`AudioKnob`, QDial)의 다섯 계기다. 위젯이 드래그·휠·키보드 입력을 전부 소유하고 스킨은 `ISkin::paintKnob`으로 그림만, `ISkin::knobGesture`로 제스처 선택만 답한다. 카드 노브는 `knob-card` 74px 정사각이고 레거시 승격 다이얼은 100x66이다.

## 공유 계약

바이폴라(게인)와 유니폴라(주파수·Q)는 한눈에 구분되어야 한다. 바이폴라의 값은 12시 디텐트에서 좌(컷)·우(부스트)로 자라고 유니폴라는 최소점에서 자란다. `valueText`가 비어 있으면(레거시 승격 다이얼) 숫자를 그리지 않는다. 회전 호에는 각도 추적(Rotary), 굴리는 드럼에는 세로 드래그(VerticalDrag, `knob-travel` 200px가 전 범위, Shift는 1/10, 고무줄 없음)가 맞고 그림과 어긋나는 제스처가 곧 위화감이다.

## 스킨별 재질

- **studio:** 호가 곧 값이다. 몸통 없이 2px `studio-border` 트랙 원, 행의 밴드 컬러(`studio-band-*`) 호를 13/9/5.5/2.5px의 4겹 스트로크 글로우로, 호 끝에 인디케이터 점(할로 6px + 코어 3px)만 그린다. 바이폴라는 12시에 발광 0 dB 앵커 틱(밖 6px/안 4px, 밴드 블룸 + 텍스트 잉크 코어)을 호보다 나중에 긋는다. 판독값은 호버·드래그 중에만 페이드 인한다.
- **minimal:** 숫자가 주인공이고 노브는 확인 계기다. 가산기의 레지스터처럼 옆에서 본 드럼이라, 원통 표면의 간격(정면은 성기고 양끝은 촘촘한)으로 놓인 1px 가로 헤어라인이 값과 함께 구르고 숫자는 두 줄 창 안에 `minimal-ink-bright`로 인쇄되며 양쪽 림의 인덱스 틱이 판독선이다. 오른쪽 주행 룰의 틱이 범위 안 위치를 말하고 바이폴라는 중앙에 디텐트 표시를 둔다. 곡선은 하나도 없다. 드래그 중에만 판독선·틱·숫자가 `minimal-accent`가 된다.
- **soft:** 다섯 스킨 중 가장 큰 노브(인셋 4px)다. 받침 디스크 한 스텝 아래(`soft-surface`) + 면 한 스텝 위(`soft-card-hover`) + 옅은 1px 보더. 트랙은 상시 보이는 파스텔(액센트를 카드 쪽으로 80% 혼합), 값 호는 25% 혼합의 진한 파스텔이다. 바이폴라 트랙은 12시에서 반으로 갈라져 왼쪽이 `soft-accent2`, 오른쪽이 `soft-accent`이고 디텐트는 부드러운 노치다. 인디케이터는 앉아 있는 쪽 색의 둥근 점(최소 4.5px)이고 값은 손잡이 아래 스타디움 배지다.
- **rack:** 포인터 노브다. 눈금은 노브가 아니라 패널에 인쇄한다(양끝 스톱 틱은 `rack-text` 메이저, 중간 틱은 `rack-muted` 마이너). 바이폴라의 0 dB 센터 틱은 플레이트에서 가장 굵고 긴 앰버(`rack-accent`) 3px 마크이고 데드존 양끝에 `-`/`+`를 각인한다. 포인터는 어두운 그림자 패스 위에 그린다. 캡 위에 값 표시창을 얹지 않으며 값은 옆의 LED 표시(`rack-graph` 우물 + `rack-accent2` 세그먼트)가 말한다.
- **matrix:** LED 링 로터리 인코더다. 바이폴라는 세그먼트 14개(짝수라 12시에 중앙 갭), 유니폴라는 15개다. 비점등 고스트 링은 `matrix-muted` 저알파(가동 80/비활성 40) 2.5px로 항상 보이고, 점등 셀은 3.5px로 컷은 `matrix-accent2`, 부스트와 유니폴라는 `matrix-accent`다. 바이폴라 디텐트 틱은 갭 바깥의 1px `matrix-text` 선이다. 정확한 값은 노브 아래 `matrix-knob-cell` 16px 박스 모노 셀이 권위를 가진다.

## 상태

studio는 할로 α 36→88→120의 휘도 사다리이고 비활성은 소등이다. minimal은 드래그 중에만 액센트이고 폭이 64px 미만이면 주행 룰을 접는다. soft는 호버에 면 색이 오르고 점이 0.5px, 드래그에 1px 자란다. rack의 활성은 앰버가 맡고 비활성은 전원 내림이다. matrix는 다크에서 점등 색에 lighter(112)의 백색 헤드룸을 더하고 비활성은 점선 보더의 빈 몸통이다.

## 소비자가 주는 것

`KnobState`(value·minimum·maximum, ratio 0..1, bipolar 플래그, 선택적 valueText, enabled/hovered/dragging/focused)와 정사각 rect. 이 미리보기는 -3.0 dB(±12 dB 범위)의 게인 노브와 40% 위치의 주파수 노브를 손으로 옮긴 정적 재현이다(hand-written from `Editor/skins/<id>/<Skin>.Controls.cpp`, `docs/skin-hooks.md`).
