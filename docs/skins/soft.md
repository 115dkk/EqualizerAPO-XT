# Soft Lab (`soft`) — 디자인 헌법

> **두려울 수 없는 설정 화면.** iPhone 설정 / macOS System Settings의 평온함.
> 둥글고, 넉넉하고, 만만하다.

## 철학

Soft Lab은 오디오 도구가 아니라 **소비자용 설정 앱**처럼 보이기를 선택한
스킨이다. 다른 네 스킨이 "프로의 장비"를 연기할 때, soft는 "겁먹은 초보자도
망칠 수 없는 화면"을 연기한다. 그래서 이 스킨의 모든 결정은 한 질문으로
환원된다: *이 요소가 화면을 더 불안하게 만드는가, 더 평온하게 만드는가?*

공식 타이브레이커는 "**의심스러우면 요소를 빼고 여백을 넣어라**"이다. 이
원칙의 가장 유명한 적용이 raw 미리보기 스트립 제거다: 카드마다 깔리는 모노
설정 원문은 "화면을 불안하게 만드는 바로 그런 요소"라서 이 스킨만
`showRawPreview = false`로 끈다(원문은 `...` 편집 버튼으로 여전히 닿는다 —
숨기는 것은 표현이지 기능이 아니다).

그림자에 대한 입장이 이 스킨의 헌법 중 가장 자주 인용된다: **그림자 이펙트는
절대 쓰지 않고, "두 단계의 배경 명도 스텝 + 아주 옅은 1px 보더"로 고도를
위조한다.** 픽커 라운드의 에이전트는 이것을 "the constitutional Soft way"라고
불렀다. 파스텔 색이 필요할 때도 새 팔레트를 들이지 않고 토큰끼리 섞는다
(`softMix(accent, card, 0.30)` 같은 식) — 그래야 다크/라이트 양쪽에서 같은
규칙이 같은 평온함을 만든다.

## 불변 규칙

1. **그림자 금지, 고도는 명도 2스텝.** 면 아래에 한 스텝 어두운 받침을 깔고,
   면은 한 스텝 밝게 + 아주 옅은 1px 보더. 이게 이 스킨의 "그림자"다.
2. **호버는 정확히 한 스텝 상승.** 카드도, 노브 면도, 픽커 행도 같은 규칙.
3. **라운드 12~14px, 스타디움 우선.** 카드·메뉴·픽커 카드는 14px(AR1 F2
   개정: studio의 8px와 한눈에 갈라지도록 상한을 끌어올렸다). 컨트롤은
   10~12px, 작은 요소(배지, 검색창, 하이라이트)는 완전한 알약(스타디움)
   형태로 굴린다.
4. **위계는 크기와 여백.** 다섯 스킨 중 가장 큰 행(48px), 가장 넓은 들여쓰기.
   밀도로 위계를 만들지 않는다. 섹션 구분도 여백이 우선이다.
5. **파스텔은 토큰 혼합으로.** 새 색을 추가하지 말고 `softMix`/`softAlpha`로
   기존 토큰을 섞는다.
6. **모든 명령 타입이 같은 실루엣.** 타입 구분은 색 타일과 본문 형태로 하고,
   카드 외형은 하나로 평온하게 유지한다.

## 빛과 상태의 문법

- **hover** — 카드가 한 고도 스텝 떠오른다(`card → cardHover`). 노브는 면 색
  상승 + 인디케이터 점이 0.5px 자란다.
- **selected** — `cardSelected` + 액센트 보더. 픽커에서는 선택 틴트의
  스타디움 하이라이트 + 부드러운 액센트 외곽선.
- **focused** — 단단한 링이 아니라 **조용한 할로**(α 90, 3px)다.
- **dragging** — 인디케이터 점이 1px 자란다. "잡혀 있음"을 알리는 가장 차분한
  신호("the calmest possible 'I am held' cue").
- **disabled** — "잠자는 슬롯". 창 배경 속으로 가라앉아 점선 윤곽만 남는다.
  **빈 슬롯이지 경보가 아니다.** 경고색·강조 금지.

## 색의 의미론

다크는 **웜 그라파이트**(#1C1A17 배경, #2F2B26 카드 — AR1 F2 개정: 옛 네이비
팔레트는 studio의 차가운 푸른 기와 겹쳐 다크에서 정체성을 잃었다), 라이트는
따뜻한 크림(#F7F4EF 배경, 보더 #E9DED1 — 차가운 회색이 아니라 베이지
계열)이다. 액센트는 #3B82F6 하나. 바이폴라 노브의 컷 쪽만 accent2를 쓰며,
그것도 카드 색으로 섞은 파스텔로 누그러뜨린다. 채널 배지는 SoftPill, 채널
그룹은 SoftShadow 스타일이다.

행의 타입 배지는 픽커의 파스텔 다색 문법을 수입한다(AR1 F2): 명령 타입
색상의 색조를 유지한 채 채도·명도를 파스텔 선반에 올려(softPastelize) 짙은
웜 잉크 글자를 얹은 스타디움 칩으로 만든다. 카드 외형은 여전히 하나다 —
다색은 칩 안에만 산다.

## 타이포그래피

DM Sans. 다섯 스킨 중 유일하게 **두 줄 행이 헌법에 부합**한다(이름 + 흐린
설명 캡션) — 여백이 충분해서 두 줄이 빽빽함이 아니라 친절함으로 읽히기
때문이다. 캡션은 모노가 아닌 본문 서체의 흐린 색으로 쓴다(모노 원문 노출은
이 스킨의 금기와 충돌).

## 구성 요소별 표현

### 노브 — "더듬을 수 없는 손잡이" (Annex K)

다섯 스킨 중 **가장 큰** 노브다(인셋 4px뿐).

- 몸통: 2스텝 고도(받침 디스크 한 스텝 아래 + 면 한 스텝 위 + 옅은 1px 보더).
- 범위 호는 **항상 보이는 파스텔 트랙**(액센트를 카드 쪽으로 ~80% 섞은
  연한 링), 값 호는 같은 색을 카드 쪽으로 25%만 섞은 진한 파스텔. **바이폴라
  트랙은 12시에서 반으로 갈라진다** — 왼쪽 절반은 accent2 파스텔(컷), 오른쪽
  절반은 액센트 파스텔(부스트). 돌리지 않아도 게인 노브임이 보인다(AR1
  F3/X3). **값 호는 12시 디텐트에서 자란다** — 부스트는 오른쪽 액센트, 컷은
  왼쪽 accent2. 유니폴라는 단색 트랙에 최소점에서 자라 한눈에 구분된다.
- 12시의 디텐트는 "부드러운 노치" — **트랙 링을 가로지르는 둥근 짧은 틱**
  으로, 값 호 위에 그려져 어디까지 돌렸든 0dB 지점이 표시된다.
  바이폴라(0dB 의미)에만.
- 인디케이터는 날카로운 선이 아니라 **둥근 점**이고, 호버/드래그에 살짝
  자란다. 행 건너편에서도 읽히는 크기(최소 4.5px, AR1 F3)이며, 바이폴라에서는
  앉아 있는 쪽의 색(부스트 액센트/컷 accent2)을 입는다.
- 값은 손잡이 **아래의 둥근 배지**(스타디움)에 담는다. 레거시 승격 다이얼은
  배지 없이 전체 높이를 손잡이에 쓴다.

### 카드(행) chrome

한 가지 평온한 실루엣. 헤더 스트립 없음(맥OS 설정 행에는 띠 제목이 없다) —
헤더는 카드 면을 공유하고, 내부 위계는 타입 칩·제목 크기·여백이 만든다.

파라미터 영역(AR1 X5): 노브 옆의 모드 박스는 진짜 선택기이므로 정직한
콤보로 입힌다 — 본문 트레이 한 스텝 위의 스타디움 필에 흐린 화살표를
그대로 보인다. 값 박스(스핀 버튼 제거, 값 스크럽)는 가라앉은 스타디움
우물이고, 포커스는 경보가 아니라 차분한 액센트 링이다.

### 참조 카드 — 다정한 참조 행 (AR2)

Include/Convolution/MultiConvolution/VST 행의 본문은 iOS 설정 행 문법의
참조 카드다(`SoftReferenceCardView`). 픽커의 타일 문법을 카드로 승격한
34px 둥근 사각 파스텔 타일(softPastelize)이 행을 이끌고, 타일 안에는
재작업 전 카드들이 쓰던 **픽토그램**(Include=문서, VST=플러그, 컨볼루션
형제=파형 — 파스텔이 형제를 가른다)이 타일 잉크로 들어간다. 영어
모노그램(In/Cn/MC/VS)보다 그림이 친숙하다는 사용자 지시의 반영이다(재작업
라운드). 이 스킨만 허락되는 두 줄 정체성(이름 + 본문 서체의 흐린 위치
캡션 — 모노 금지 준수)이 따르며, 위치 캡션은 컨테이너 접두(`Surround\`,
후행 구분자가 폴더임을 말한다)로 쓴다. IR 판독값은 개별 **파스텔 스타디움
칩**이다. 결손은 경보가 아니라 개체의 상태 전이: 타일이 파스텔
danger(빈 참조는 한 단 더 누그러진 warning)로 바뀌고 픽토그램 대신
스트로크 느낌표가 들어가며, 캡션이 as-written 참조를 보여 주고,
"Locate..." 액센트 파스텔 필이 주인공이 된다. MISSING 대문자 배지도
빨간 텍스트 벽도 없다. ABS 배지는 타이브레이커로 생략했다(절대 경로는
캡션의 드라이브 문자가 이미 말한다). 액션은 스타디움 아이콘 필이다.

### Copy 라우팅 — 수식 블록 (BlockChip)

각 출력이 하나의 둥근 "수식 블록"이다: `VSL = 0.86·L − 0.5·R`을 친근한 채널
칩과 계수 칩으로 조립한다. 블록은 액센트 가장자리의 둥근 카드이고, 왼쪽에
대상 채널 색의 둥근 막대가 붙는다. 행 끝의 점선 둥근 `[+]` 칩이 소스 추가
메뉴를 연다(장치 채널이 블록으로 시딩된다). 계수를 비우면 그 칩이 빠진다.

MultiConvolution 카드가 같은 수식 블록을 고정 소스 모드(RoutingPortModel)로
재사용한다: `L = ⓪ + ①`처럼 파일 채널 번호가 칩이 되고, `[+]` 메뉴는 파일
채널만 내놓는다. 팩터가 없으므로 계수 표기는 등장하지 않고, 칩 더블클릭이
그 칩을 제거한다.

### 장치·채널·주석·스테이지 카드 (Phase 2)

선택지는 전부 스타디움 알약이고 상태는 셋뿐이다. ON = @ACCENT@ 파스텔
채움, OFF = 한 스텝 가라앉은 조용한 알약(@SURFACE_SUNKEN@ + 옅은 1px
보더), 잠듦 = 점선 + 창 배경 침강 + 뮤트 잉크의 **삼중 조합**. 호버는
정확히 한 스텝 상승(값 스크럽 우물의 그 스텝). 파생 규칙: **점선 윤곽
단독(풀 잉크·칩 고도 유지)은 '하드웨어가 보증하지 않는 실체'**(미설치
엔드포인트, 가상 채널, 미지 셀렉터)를 뜻하며, Copy의 점선 `[+]` 추가 칩과
같은 뿌리다. 잠듦은 삼중 조합이어야만 성립한다. 마스터(All devices/ALL)는
같은 고도에서 weight와 더 깊은 ON 파스텔로만 서열을 만들고, 잠듦 규칙은
속성 변형 전체를 덮는 그룹 선택자로 가족의 맨 뒤에 둔다(잠듦이 최종 승자).
재생/캡처 구분은 툴팁(타이브레이커: 요소를 빼고 여백을). Stage는 어휘가
셋으로 고정된 유일한 카드라 min-width 64px 같은 폭 알약의 매치된 스위치
뱅크로 읽힌다. Comment는 알약이 없는 유일한 카드로, 확립된 웜 앰버 파스텔
(DirtyStatusBadge의 warmer-never-an-alarm)을 메모지 종이색으로 재사용하고
'#'는 메모의 작은 스티커다. 네 에디터 컨테이너는 투명(트레이 밑 @BG@ 패치
금지).

### 필터 픽커 — 둥근 설정 메뉴

소비자 설정 앱의 메뉴 카드 그 자체가 목표였다.

- 스타디움 알약 검색창.
- 48px **두 줄 행**: 굵은 템플릿 이름 + 흐린 캡션(비모노). 빈 줄이나 콜론으로
  끝나는 템플릿 줄("Include:")은 잘린 글처럼 읽히므로 표시층에서 친절한
  문구("Choose the details after adding")로 바꾼다(AR1 F5) — 원문은 툴팁과
  실제 삽입 줄에 그대로 산다.
- 항목마다 iOS 설정풍 **둥근 사각 색 타일**에 **항목별 픽토그램**(재작업
  라운드: 그림이 영어 활자보다 친숙하다는 사용자 지시). 키는 번역되는
  이름이 아니라 템플릿 줄의 명령어이고, biquad는 타입 토큰까지 갈라 EQ
  8형이 각자의 응답 곡선 글리프(eq-*.svg)를 단다. 기능 아이콘은 modern
  세트의 스트로크 문법으로 새로 그렸다: 문서(Include)·파형(Convolution)·
  겹층(MultiConvolution)·플러그(VST)·세로 슬라이더(GraphicEQ)·볼륨
  램프(Preamp — 노브 그림은 시계로 오독되어 교체)·시계(Delay)·
  스피커(Device)·채널 목록+체크(Channel — 이 명령은 채널 **선택**이다;
  분기 화살은 신호 분할로 오독되어 교체)·직렬 체인(Stage)·교차
  화살(Copy — 채널 간 라우팅)·확성 파형(Loudness)·말풍선(Comment). 매핑되지 않은 미래
  템플릿은 AR1 F4 모노그램(여러 단어=이니셜 둘, 한 단어=앞 두 글자,
  충돌 시 카탈로그 순서로 유일화)으로 물러난다. 섹션 파스텔이 둘째
  구분자다.
- 카테고리 헤더는 같은 파스텔로 틴트된 알약. 파스텔 색상은 카탈로그 순서로
  카테고리에 배정된다(순서가 바뀌면 색이 바뀌는 건 의도된 코스메틱 트레이드).
- 섹션 구분 장치는 **알약 위의 여백뿐**이다.
- 호버는 한 스텝 상승, 현재 행은 스타디움 하이라이트.
- 검색이 빗나가면 **다정한 빈 상태 카드**: 한 스텝 위의 둥근 카드에 파스텔
  원 + 스트로크 돋보기, 본문 잉크의 제목과 흐린 캡션. 경고색 없음.

## 하지 말 것

- 그림자/블러 이펙트. 고도는 언제나 명도 2스텝으로 위조한다.
- 모노스페이스 원문(설정 줄)을 본문에 노출하기. raw 미리보기를 다시 켜는
  것은 헌법 개정 사안이다.
- 날카로운 모서리, 가는 헤어라인 격자, 빽빽한 표. (matrix/minimal의 어휘다)
- 비활성·오류 상태에 경고색을 입혀 "알람"으로 만들기.
- 새 파스텔 팔레트 추가. softMix로 만든다.
- 여백을 줄여 정보를 더 넣기. 의심스러우면 빼고 여백을 넣는다.

## 이웃 스킨과의 경계

가장 가까운 이웃은 **studio**다(둘 다 표준 카드 실루엣). 경계는 studio 헌법
문서의 경계 절과 동일하다: 라운드 8 vs 14, 표면 온도(차가운 네이비 유리 vs
웜 그라파이트/크림), 고도 전략(알파 유리+반사광 vs 명도 2스텝), 노브(발광 호
vs 큰 몸통 손잡이 + 파스텔 트랙), raw 미리보기(유지 vs 제거). soft가
빛·글로우·반사 어휘를 집어 들면 studio를 침범한 것이다. soft의 빛은
"떠오름"(고도)이지 "발광"(광원)이 아니다.
